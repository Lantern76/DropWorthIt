# DropWorthIt

Free, no-wallet-connection directory of crypto airdrops. Live: https://maple956.github.io/dropworthit/

**Not financial advice. Do your own research. Never share your seed phrase; only use the official links.**

Data: `data/airdrops.json` (each entry has an `official` link plus third-party citations). Build: `node build.js` → `dist/`. Deployed by pushing `dist/` to the `gh-pages` branch.
